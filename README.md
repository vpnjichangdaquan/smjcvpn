日常浏览

网络异常排查

如果客户端无法正常连接，可以按照下面的顺序检查。

订阅无法更新

检查：

- 订阅地址是否复制完整
- 账号套餐是否正常
- 当前网络是否可以访问订阅服务器
- 客户端是否支持该订阅格式

节点无法连接

可以尝试：

重新更新订阅
↓
更换节点
↓
更换节点地区
↓
重启客户端
↓
检查本地网络

网页可以打开但速度较慢

建议：

- 更换节点
- 避开网络高峰
- 测试不同地区线路
- 检查本地 Wi-Fi / 宽带
- 更新客户端版本

某个网站无法访问

首先确认是不是：

- 节点本身问题
- DNS 问题
- 客户端规则问题
- 目标网站地区限制
- 目标网站封禁当前 IP

不要仅通过更换一个客户端来判断线路是否正常。

Q：是不是所有节点速度都一样？

不是。

节点速度会受到多种因素影响，例如：

- 用户所在地
- 运营商
- 国际出口
- 节点负载
- 时间段
- 目标网站服务器

因此建议实际测试后再选择常用节点。

---

Q：为什么昨天能用，今天突然不行？

可能原因包括：

- 节点负载发生变化
- 节点 IP 被目标平台限制
- 订阅配置发生变化
- 本地网络环境改变
- 目标服务调整地区策略

可以先更新订阅并更换其他节点测试。
